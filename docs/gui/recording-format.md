# FusionX GUI MCAP recording format

[GUI guide](README.md) · [Calibration](calibration.md) · [Troubleshooting](troubleshooting.md)

Profile: **`touchtronix.raw.v4`**. Files: `recording_###.mcap` in **Save Folder**, using the next unused index. Open them after **Saved**.

## Topics

| Topic | Encoding / schema | Content |
|---|---|---|
| `/camera/head/stereo/h264` | Protobuf, `foxglove.CompressedVideo` | Intact 3840×1200 side-by-side stereo at 30 FPS; `format="h264"`, `frame_id="head_left"`. |
| `/camera/wrist/{lh,rh}/h264` | Protobuf, `foxglove.CompressedVideo` | Assigned wrists, 1920×1080 at 30 FPS. |
| `/camera/head/{left,right}/calibration` | Protobuf, `foxglove.CameraCalibration` | Per-eye 1920×1200 factory calibration. |
| `/calibration/camera/head/json` | JSON | Verbatim factory flash calibration and device identity. |
| `/camera/head/imu` | JSON, `touchtronix.UvcImuSample` | Accel m/s², gyro rad/s, temperature, raw fields, timing. |
| `/glove/{lh,rh}/tactile` | JSON, `touchtronix.GloveTactileSample` | Raw pressure/bend and optional calibrated output. |
| `/glove/{lh,rh}/imu` | JSON, `touchtronix.GloveImuSample` | Euler angles and raw motion values. |
| `/calibration/glove/user/json` | JSON | Selected wearer calibration. |
| `/tf_static` | Protobuf, `foxglove.FrameTransform` | Factory `head_left`→`head_right` geometry. |

Wrists provide video only. No wrist IMU/calibration, dynamic `/tf`, or glove-to-camera transform is generated by the standard setup.

## Glove tactile fields

| Field | Meaning |
|---|---|
| `hand` | Operator-assigned `lh`/`rh`. |
| `sample_idx` | Per-topic sequence. |
| `timestamp` | `host_timestamp_ns / 1_000_000_000`. |
| `host_timestamp_ns` | Integer Unix host decode time; MCAP log/publish time. |
| `device_timestamp_ms` | Separate uint32 elapsed counter; start resets it. |
| `message_sequence` | Wire NUM; repeats allowed. |
| `finger_pressure` | Five named 4×4 patches; row-major from top-left, ADC 0–4096. |
| `finger_bend` | Five ADC values: thumb → little. |
| `pressure_raw` | 80 pressure wire channels. |
| `bend_raw` | Five bend wire channels: little → thumb. |
| `finger_force_N_total` | Optional five polynomial total forces, N. |
| `finger_pressure_kPa_pixels` | Optional five-by-16 contact pressures, kPa. |
| `finger_pressure_N_pixels` | Matching five-by-16 forces, N = kPa × 0.0225. |
| `finger_pressure_saturated` | Matching booleans from raw ADC `>=4000`. |

Converted fields need matching calibrations. Raw ADC stays intact; tactile/bend images are generated during playback.

Glove IMU uses the same hand/timing/sequence fields plus `imu_euler_deg` (pitch, roll, yaw), `imu_gyro_raw`, and `imu_accel_raw`. Raw motion scaling is unverified; inspected values were zero. No quaternion/magnetometer is transmitted.

## Camera video and timestamps

| Property | Contract |
|---|---|
| Capture | DirectShow on Windows; V4L2 on Linux. |
| Encoding | Intel QSV, then CPU `libx264`; native resolution, no GPU required. |
| H.264 | One-second closed GOP; no B-frames/lookahead; repeated SPS/PPS/AUD. Each stream/segment begins on a keyframe. |
| Video time | Capture epoch PTS: DirectShow wall clock or epoch-converted V4L2 timestamp. Host receipt time is diagnostic. |
| Pairing | Downstream, within about one frame; no runtime matching/resampling. |
| Startup | Required head IMU/factory calibration and a keyframe from every selected camera; failure creates no MCAP. |
| Rotation | After 9,000 head units, at the next head keyframe. Wrists wait for their own next keyframe. Calibration replays into every segment. |

Split the stereo image downstream if needed.

## Head IMU and calibration

| Data | Interpretation |
|---|---|
| Head IMU time | SDK monotonic host clock mapped to Unix; not verified sensor-capture time. Every valid read is retained without pacing. |
| `imu_timestamp_raw` | Preserved, including repeats. |
| `read_duration_ns`, `delivery_delay_ns` | Optional read/delivery diagnostics. |
| Factory JSON | Preserved verbatim; centimeter extrinsics become meters (~6 cm baseline). |
| Foxglove calibration | First 8 of 14 distortion coefficients, rational-polynomial model; both projection matrices use right-eye intrinsics. |

## Recovery and completeness

Same-port sensor reconnects retry until stopped; video resumes on a keyframe. Unexpected head IMU helper/reader exit stops the episode and preserves captured data. Real gaps may remain; inspect counts and timestamps.

Stop closes the shared capture gate before teardown. Build/segment metadata does not add timestamped lifecycle topics.

## Foxglove playback

Install the bundled [panel and layout](troubleshooting.md#foxglove-panel-or-layout-is-missing), then open MCAP in Foxglove Desktop. The tactile panel supports raw ADC and calibrated pixel pressure at 0–345 kPa, with saturation flags.
